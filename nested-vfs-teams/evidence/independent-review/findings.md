Original output is preserved in `original-failures.json`; the baseline full canary in `baseline/canary.json` passed 60 assertions in fresh disposable state, with 11 verified artifacts and one intentional exhausted retry. Passing that canary did not cover the findings below.

1. **Verification status authority — high within trusted API contract.** `accept_verification` accepts a caller-supplied PID, Boolean content match and unchecked receipt identifier. A producer writes incorrect bytes; a fabricated observation promotes the job to VERIFIED. This does not require editing a database. Remediation should bind actual coordinator-spawned observer execution to job, artifact and durable native receipt, and reject arbitrary observation promotion. This remains a trusted local adapter boundary, not authenticated hostile-process security.
2. **Nested storage symlinks — high within static namespace containment.** The member root itself is checked, but `objects/` and `vfs.sqlite3` links are followed. The retained probe writes object bytes outside the member scope and separately opens a linked external database. Validate all backing paths before any read/write, including the observer read path and runtime queue/template/team backing stores. Static path validation does not provide TOCTOU resistance against hostile filesystem races.
3. **Lease time starts before lock acquisition — medium availability.** A claim blocked for 0.3 seconds behind a SQLite writer returns a 0.1-second lease already expired, consuming an attempt without a usable work window. Compute the lease clock after acquiring the write transaction.
4. **Actual memory measurement omitted — evidence gap.** Original report records configured RLIMIT_AS and elapsed/disk observations but no observed worker/verifier peak RSS. Report OS-observed per-process resource usage separately from configured ceilings; do not call the limits memory measurements.

Existing source correctly rejects cross-team membership, inherited permission escalation, stale claim token/epoch, malformed artifact paths and a member-root symlink. The baseline demonstrates two-process single claim, persisted retry budget, actual process exits before and after artifact commit, continuation replay retaining one binding and corrupt artifact observer rejection. These observations do not confer remote authentication, native dispatch binding or hostile-code OS confinement. All processes share executor filesystem authority.
